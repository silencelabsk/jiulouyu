- 所有超时、轮次、阈值、文案候选集均通过 `AutomationConfig` 与 `LocatorRegistry` 从 properties 文件读取，源码中不出现魔法数字。
- 对外部可插拔能力（如驱动实现）通过接口抽象（`DriverFactory`）+ 配置分发（`createDriverFactory` switch）实现，新增实现只需加 case 分支，上层零感知。
- 需要随 session 重建刷新的组件实现 `DriverAware` 接口并通过 `DriverRegistry.register` 集中注册，由 `RecoveryHandler` 统一调用 `refreshAll(newDriver)` 更新引用。
- 长任务异常路径统一通过 `RunLogger.captureSnapshot(tag)` 落盘现场（如 `fatal_error`、`recovery-failed`），再以非零退出码结束，避免裸异常堆栈。
- 幂等清理通过 `AtomicBoolean` 守护（ShutdownHook 与 finally 双重触发场景），确保 `logger.stop()` 与 `driver.quit()` 仅执行一次。
- 测试全部采用离线回放模式：使用 `src/test/resources/fixtures/*.xml` 真实 UI 树快照 + 手写测试替身，不连接真机、不启动 Appium session。
