### 干跑（dry-run）
- 定义：自动化运行的一种安全模式：连接真机、抓取 UI 树快照、识别页面状态，但**不执行任何点击、不播放广告、不领取奖励**。用于在校准 `locators.properties` 文案候选集和 `StateDetector` resource-id 之前验证页面结构是否可被稳定定位。对应命令行参数 `--dry-run` 与配置键 `runtime.dry.run`。
- 别名：dry-run、探针模式

### 免广告时长
- 定义：番茄免费小说 App 内通过观看激励视频获得的「免广告」权益时长（单位分钟）。自动化目标是在一轮或多轮流程中累计达到目标值（默认 120 分钟），达到后优雅收尾。该权益由穿山甲 SDK 发放，受每日配额限制。
- 别名：免广告时长、free minutes

### 广告轮次（ad round）
- 定义：一次完整的「进入广告入口 → 观看视频 → 关闭广告 → 领取奖励」的子循环。工程对单入口轮次（`flow.max.ad.rounds.per.entry`）和全局轮次（`flow.max.total.ad.rounds`）设置熔断阈值，防止无限消耗每日配额。
- 别名：ad round、广告轮次

### 自愈（Recovery）
- 定义：当自动化流程因弹窗、session 断开、页面异常等偏离预期状态时，按从弱到强的五级策略自动恢复：关闭通用弹窗 → back 返回 → 重启 App → 导航回书架 → 重建 Appium session。超过重试上限则落盘诊断退出。
- 别名：多级自愈、recovery

### 心跳保活
- 定义：独立 daemon 线程每固定间隔（默认 30 秒）调用轻量 API（如 `getWindowSize()`）维持 Appium session 活跃，避免在广告视频长静默期触发 newCommandTimeout 断连。探活失败会置位 sessionAlive 供上层感知。
- 别名：heartbeat、保活

### 进度持久化
- 定义：将已领取的免广告分钟数、总广告轮次、已使用书籍集合等信息写入 `progress.properties`，支持程序重启或 session 重建后断点续跑；per-book 的 usedBooks 按当天有效，跨天清空。
- 别名：progress.properties、断点续跑

### 环境自检（--doctor）
- 定义：启动时只检查 ANDROID_HOME、adb、设备在线、Appium Server 就绪、App 已安装这五项环境条件，不创建 Appium session、不操作手机；全部通过返回 0，任一硬性检查失败返回 1。
- 别名：doctor、环境自检
