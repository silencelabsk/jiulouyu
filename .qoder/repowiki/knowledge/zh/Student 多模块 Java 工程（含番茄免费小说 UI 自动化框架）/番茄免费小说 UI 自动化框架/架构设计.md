工程采用 Maven 构建（pom.xml 中 pin 了 Appium Java Client 9.5.0 与 Selenium BOM 4.34.0），通过 `FanqieRunner.main` 作为唯一入口装配组件并以 maven-shade-plugin 产出 fat-jar 脱离 IDE 长跑。

内部按 README 明确的分层组织，依赖方向严格自上而下：
- `config` 层：`AutomationConfig` 集中加载 `automation.properties`（带默认值兜底，支持外部文件覆盖）；`LocatorRegistry` 加载 `locators.properties` 文案候选集，所有业务阈值与超时均从此处读取，实现“改配置不改代码”。
- `core` 层：`DriverFactory` 接口 + `AppiumUiAutomator2DriverFactory` 实现封装 Appium session 生命周期；`StateDetector`/`PageState` 将 UI 树识别为状态枚举；`RunLogger` 提供心跳保活、截图/快照落盘与统计汇总；`GestureSupport`/`WaitSupport`/`UiSnapshot`/`UiNode` 提供底层交互原语；`DriverRegistry` + `DriverAware` 在 session 重建后统一刷新 driver 引用。
- `page` 层：`BookshelfPage`/`ReaderPage`/`AdFlowPage` 继承 `BasePage`，封装书架、阅读页、广告流程的具体操作。
- `task` 层：`FanqieAdWatchTask` 编排外层循环与翻页主流程；`AdWatchStateMachine` 管理广告子循环、进度持久化与熔断；`RecoveryHandler` 实现五级自愈（弹窗关闭→back→重启App→导航书架→重建session）。

扩展点：`DryRunProbe` 提供只连接不点击的安全校准模式；鸿蒙 NEXT 路线通过预留 `driver.type` 与 `DriverFactory` 接口扩展点实现零改动替换驱动实现。
