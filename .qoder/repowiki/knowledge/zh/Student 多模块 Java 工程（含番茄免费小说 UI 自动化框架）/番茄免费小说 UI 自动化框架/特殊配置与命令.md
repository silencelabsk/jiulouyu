构建与运行命令集中在 `pom.xml` 与 `README.md`：`mvn clean package` 产出 `target/fanqie-automation-1.0.0.jar`；`java -jar ... --doctor` 仅做环境自检；`--dry-run` 安全探针只 dump UI 树不点击；`--cycles N --pages N` 控制联调规模；`--reset-progress` 清除 `progress.properties` 累计进度；`--config <path>` 外部覆盖配置文件无需重新编译。需先启动 `appium --base-path /` 且设备满足开发者选项、USB 调试、仅充电模式允许 ADB 调试等 7 项手机侧设置。
