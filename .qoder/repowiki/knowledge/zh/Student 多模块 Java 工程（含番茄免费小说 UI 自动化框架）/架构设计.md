工程以 src/ 为 IDE 默认源码根（Main.java + demo01 基础示例），真正的业务代码位于同级 automation/ 子模块：该子模块采用 Maven 标准结构（src/main/java com.fanqie.auto.*、src/test/java、resources/fixtures），通过 pom.xml 管理依赖并独立打包；根 Student.iml 将两个来源组织在同一 IntelliJ 工作区中，各子模块可各自运行但共享同一工程配置。自动化框架内部按 config/core/page/task 分层，核心 DriverFactory/AppiumUiAutomator2DriverFactory 统一驱动生命周期，Task 接口抽象用例流程，BasePage 封装页面操作，StateDetector/RecoveryHandler 实现多级自愈，RunLogger 输出日志与快照到 logs/snapshots。
